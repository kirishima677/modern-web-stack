pnpm（Performant npm）は、圧倒的な「インストールの速さ」と「ディスク容量の節約」を両立したNode.js向けの高性能なパッケージマネージャーです。従来のnpmやYarnのようにプロジェクトごとにパッケージの実体を何度もコピーするのではなく、PC内の「共通の倉庫（グローバルストア）」にファイルを1回だけ保存し、各プロジェクトからはそこへ「ハードリンク」を張る仕組みを採用しています。

💡 主なメリットと特徴ディスク容量の大幅な節約: 10個のプロジェクトで同じライブラリ（Reactなど）を使っていても、PC内には1個分の容量しか消費しません。爆速のインストール: すでに倉庫にあるパッケージを導入する場合、リンクを張るだけなので一瞬で処理が終わります。幽霊依存（Phantom Dependency）の防止: package.json に記載していない間接依存のライブラリ（本来使えないはずの隠れた部品）をコードから呼び出せないようにする厳密な仕組みを持ち、本番環境での予期せぬバグを防ぎます。強力なモノレポ対応: 複数の独立したプロジェクトを一元管理できる「ワークスペース」機能が標準で組み込まれています。

🛠️ よく使う基本コマンド
npmとほぼ同じ感覚で操作できますが、少しだけ書き方が異なります。

- 初期化: pnpm initパッケージのインストール: pnpm install （または pnpm i）
- パッケージの追加: pnpm add <パッケージ名>
- 開発環境向けに追加: pnpm add -D <パッケージ名>
- パッケージの削除: pnpm remove <パッケージ名>
- スクリプトの実行: pnpm <スクリプト名>（run を省略可能。例: pnpm dev）

⚙️ 導入方法Node.jsがインストールされている環境であれば、公式のインストール手順に従うか、以下のnpmコマンド等で簡単にグローバルインストールできます。

```bash
npm install -g pnpm
```

コードは注意してご使用ください。もし既存のプロジェクトをnpmからpnpmへ移行したい場合や、設定ファイル（pnpm-workspace.yaml など）の具体的な書き方を知りたい場合は、プロジェクトの構成（単一かモノレポかなど）を教えてください。最適な手順をご案内します。

###　詳細

Fastifyとは？ 🤔
Fastify は、Fastify公式サイト によると、Node.js向けに設計された「超高速」で低オーバーヘッドなWebフレームワークです。
Express.jsと比べ、パフォーマンスに重点を置いており、以下のような特性を持っています：

驚異のパフォーマンス：最適化された内部設計により、リクエスト処理が非常に高速。
JSON Schemaによるバリデーション：自動的なシリアライズ・デシリアライズで、レスポンスも高速に生成。
プラグインシステム：独自のプラグイン機構により、機能の拡張がスムーズで保守性が高い。
Developer Experienceの向上：シンプルなAPIと豊富なドキュメントで、初心者でも扱いやすい。

Fastifyの特徴 ✨
Fastifyを採用する理由はたくさんあります。主なポイントを整理すると：

高効率なルーティング
→ ルーティングのパフォーマンスが最適化され、リクエストごとのオーバーヘッドが非常に低いです。

柔軟なプラグインシステム
→ ミドルウェアではなく、プラグインの形で機能を追加できるため、アプリケーションのモジュール化が進みます。

JSON Schemaのサポート
→ 入力のバリデーションやシリアライズの自動化で、エラーを未然に防ぎ、パフォーマンスを向上。

優れたドキュメントとコミュニティ
→ 公式サイトやGitHub上での情報が充実しており、問題解決や機能追加の際に大変心強いです。



TypeScript のサポート
Fastify には typings ファイルが同梱されていますが、使用している Node.js のバージョンによっては、@types/node をインストールする必要がある場合があります。
以下の例は、HTTP サーバーを作成するものです。
使用している HTTP バージョンに対応する型情報を渡します。型情報を渡すことで、ルーティング内の基盤となる HTTP オブジェクトに対して、正しい型付けされたアクセスが可能になります。
HTTP/2 を使用する場合は、<http2.Http2Server, http2.Http2ServerRequest, http2.Http2ServerResponse> を指定します。
HTTPS の場合は、Server の代わりに http2.Http2SecureServer または http.SecureServer を指定します。
これにより、サーバーハンドラ内でも reply.res に対して正しい型付けがされた http.ServerResponse を取得できるようになります。

```ts

import Fastify, { FastifyInstance, RouteShorthandOptions } from 'fastify'
import { Server, IncomingMessage, ServerResponse } from 'http'

const server: FastifyInstance = Fastify({})

const opts: RouteShorthandOptions = {
  schema: {
    response: {
      200: {
        type: 'object',
        properties: {
          pong: {
            type: 'string'
          }
        }
      }
    }
  }
}

server.get('/ping', opts, async (request, reply) => {
  return { pong: 'it worked!' }
})

const start = async () => {
  try {
    await server.listen({ port: 3000 })

    const address = server.server.address()
    const port = typeof address === 'string' ? address : address?.port

  } catch (err) {
    server.log.error(err)
    process.exit(1)
  }
}

start()

```
